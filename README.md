# Workout Tracker API

API RESTful hecha con Node.js y Express para gestionar usuarios, rutinas, ejercicios y progreso. Organizada en capas (routes y controllers) para mantener el código limpio y escalable.

## Requisitos

- Node.js (v18 o superior)
- npm
- Git

## Cómo ejecutarlo

```bash
git clone https://github.com/jeropulga/workout-tracker-api.git
cd workout-tracker-api
npm install
cp .env.example .env
npm run dev
